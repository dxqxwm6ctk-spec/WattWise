# ترتيب لوحة التحكم (الموقع): تصميم "مخطط البيت"

## الفكرة بجملة
الشاشة مقسومة لقسمين: **عمود الوكيل** على اليمين (شو بدّك، شو عم يعمل، وشو بستنّى منك)، و**البيت** على اليسار مرسوم كمخطط طابق، كل غرفة مربع فيه استهلاكها وأجهزتها.

## عمود الوكيل (يمين)
1. **إيقاف طوارئ**: فوق، دايمًا ظاهر.
2. **الهدف**: نص الهدف، وتحته ثلاث أرقام: الفاتورة لحد اليوم، المتوقع آخر الشهر، والحد اللي حطّيناه. زر «غيّر الهدف» بيفتح خانة الكتابة.
3. **طلب الموافقة**: أهم إشي بالعرض، فحطّيناه مباشرة تحت الهدف. فيه السبب، كم بيسحب الجهاز الآن، التوفير التقريبي، عدّاد الوقت، وزرّين «موافق» و«ارفض». تحته جملة: بدون رد لا يُنفَّذ شيء.
4. **التنبيهات**: آخر ٤ تنبيهات.
5. **مراحل عمل الوكيل**: السبع مراحل بشكل خط عمودي. المرحلة الحالية ملوّنة (برتقالي لما ينتظر موافقتك). خطة الوكيل التفصيلية مسكّرة تحتها، بتنفتح بضغطة.
6. **سجل القرارات**: آخر ٦ قرارات وزر «الكل». (شرط أمان: كل قرار وسببه ونتيجته ظاهرين.)

## البيت (يسار)
1. التنقّل بين البيت / المبنى (١٠ غرف) / المختبر، حالة الوكيل، وقائمة «المزيد».
2. أزرار سيناريوهات المحاكي (بس لما البيانات من المحاكي).
3. أربع أرقام: الاستهلاك الآن، فاتورة الشهر، المتوقع، والتوفير المُقاس.
4. **مخطط البيت**: كل غرفة مربع، والجدران خطوط غامقة.
   - غرفة **مشغولة**: أبيض.
   - غرفة **فارغة**: مخطّطة بخطوط خفيفة.
   - غرفة **فيها هدر** (جهاز شغّال وهي فاضية): خلفية برتقالي فاتح وإطار برتقالي.
   - كل جهاز زر صغير: النقطة الخضراء يعني شغّال، والرقم جنبه هو الواط. اضغطه لتشغّله أو تطفيه. الأجهزة الحرجة (الثلاجة، إنذار الحريق) إطارها متقطّع ومكتوب «محمي»، وما بتنضغط.
5. **رسم اليوم**: الخط الغامق هو الاستهلاك الفعلي، والخط المتقطّع هو المتوقع بدون الوكيل. المساحة الخضراء بينهم هي التوفير. جنبه التوفير المُقاس بالدينار و CO₂، شرائح التعرفة، والتوقّع للساعات الجاية.
6. أدوات إضافية مسكّرة: تعريف الأجهزة، الجداول، الفاتورة والتقارير.

## على الموبايل
كل إشي بيصير عمود واحد: الهدف، ثم طلب الموافقة، ثم البيت (عمودين غرف)، والسجل بالآخر.

## الشكل
خلفية بيضا، خط IBM Plex Sans Arabic للنص و JetBrains Mono للأرقام (عشان الأرقام تصف تحت بعض). لون واحد أخضر مزرق للإشي اللي تمّ أو توفّر، برتقالي بس للإشي اللي بستنّاك، وأحمر بس للإيقاف. ما في تدرّجات ألوان ولا إيموجي ولا عناوين إنجليزية.

`frontend/index.html`، `frontend/css/dashboard.css`، `frontend/js/dashboard.js`. ما تغيّر أي شيء بالخادم (backend)، فكل الأوامر ونقاط الـ API نفسها.
